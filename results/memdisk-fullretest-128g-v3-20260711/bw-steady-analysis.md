## 3. randrw 128-job 聚合验证

- v2 问题：分析脚本用 last data_direction 覆盖同一秒的读/写 → 混合 → B randrw-r1(R) = 164 MB/s（> 118 NIC = 物理不可能 = 错误）
- v3 修正：每秒按 dir=0/dir=1 分开求和 128 job → 每方向 142-156 个稳态点 → 中位数可靠
- v3 结果：B randrw R max=95.0, W max=90.5 → 均 < 118 NIC → **无物理不可能值 ✅**

## 4. 关键结论

1. **randwrite 121/120 是缓冲假象**：稳态中位数 ~111 MB/s（A/B 一致），< 118 NIC = 合理。**127→109 假象再证（v2 也 109，v3 111，一致）**。
2. **写类暂态 4-8%**（单流/多流），**randwrite 暂态 7-8%**（最显著）。
3. **读类暂态 <2%**（可忽略）。
4. **A 组 7/8 过 59**（randread FAIL，randrw R/W FAIL），**B 组 8/8 全过 59**。
5. randrw bw_log 128-job 聚合后每方向 142-156 个稳态点，中位数可靠，**无 v2 的 164 不可能值**。
