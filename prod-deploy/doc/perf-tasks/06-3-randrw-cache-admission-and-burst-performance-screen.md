## 一、背景与唯一主问题

**主问题**：在固定256K randrw与固定缓存预算下，能否获得优于同轮无缓存基线、可重复的完整测试平均R/W？
同时选择S/W中值得后续使用的配置；“超过有方”先作为历史数值目标，不伪装成新的同场竞品结论。

冻结源码 `06-2/20260916-091446/build/juicefs-v1.4.1-b-catchup-source.tar.gz` 说明：

- `cached_store.go:368--370`：无writeback时，默认只缓存小于BlockSize的写块。
  B256卷完整256K写默认不入缓存；`--cache-large-write`可把新写完整块也提交缓存队列。
  入缓存发生在PUT路径中，但不把原有Flush的远端上传完成条件改成本地stage确认。
  前提是`:357`的`sync := s != nil`：非WB上传在`:467`传入`s`，该缓存准入分支才生效；
  WB后台上传在`:448`传入`nil`，不走同一分支。
- `disk_cache.go:783--813`：writeback把stage硬链接到raw，上传后保留作读缓存；
  不是复制两份块。覆盖写使用新object key，不是在旧缓存文件原地修改。
  `cached_store.go:424/607--608`要求块长严格小于writeback阈值；默认阈值为`BlockSize+1`，
  因此B256卷的完整256K块可进入stage，不等于本负载已把WB关掉。
- 因此06-1未验证“无WB + cache-large-write”。其WB条件下无需再靠该flag缓存stage块，
  不等于关闭WB后该flag也无意义。
- 全程平均提高但末窗下降，可以是有效的有限突发收益；须报告数据确认/排空风险和资源需求，
  不能外推成长期持久化带宽。

不再默认扫描容量、U450/U600、upload-delay或内核dirty参数，不改fio IO模型或源码。
§七仅允许在收益复现后，按证据另批必要的两点归因，不恢复五档容量全矩阵。

1. **先冻结实际计划**：只读核实UUID/META、128文件名/inode/大小、二进制、fio版本、Ceph

   `/mnt/jfs-cache/04tmp3/<本RUN子目录>`，历史许可不是本轮自动授权。
2. **缓存起点对称**：S/W每格独立空目录，同一60秒预热。预热本身也会回填写出Dirty，
   所以恢复门必须位于“预热之后、正式fio之前”，不能只检查挂载前。
   已注册的staging指标、uploading及私有rawstaging归零；此版JuiceFS未注册pending指标，
   在原始记录中标`NA`，不得伪写为实测0；TiKV pending-compaction是另一指标。
   宿主Dirty不超过安静期P95+8GiB、Writeback不超过P95+1GiB，
   持续30秒；保存缓存占用/命中计数和从预热结束到开跑的时长。基线由首次负载前120秒安静观测冻结，
   不用宿主全局Dirty=0作不现实门；无法区分业务脏页或15分钟仍不满足则停止并评审。
3. **不要把缓存吸收清理掉**：上述约束只控制起点，不要求正式窗Dirty/staging不增长，
   不要求本地设备必须发生大量读。页缓存供给是允许的整机缓存资源，但须说明资源来源。
   报告须并列同窗blockcache命中字节、缓存设备读字节和宿主内存；命中高而设备读近零时，
   改述为“本地缓存路径主要由宿主页缓存供给”，不得声称验证了NVMe介质读性能或容量曲线。
   这限制介质归因，不取消真实的整机缓存带宽收益；设备统计与命中字节不强制逐字节相等。
   不drop_caches、不全局sync、不改内核dirty比例，不以cache=0删除其他业务缓存。
4. **后端状态**：每格记录对象数、TiKV延迟/compaction、OSD compact三指标及健康。
   默认被动恢复，不轮间relayout，不自动共享卷GC/主动OSD compact。若不能维持可比起点，
   暂停并单独审批一次精确恢复计划；不把GC后对象数相同等同于TiKV历史状态相同。
5. **空间/业务保护**：stage不计入96GiB预算，须在开跑计划中单列**批准的最大暂存占用**、读缓存、

   可用空间下降超过“读缓存+批准暂存上限”或触及绝对可用空间/内存下限，即停该格并保留挂载；

   scrub仅在本phase内经授权暂停，保存原flags并精确恢复；禁止与05-3/06-2b等负载同时运行。

## 四、判定与竞品目标

分别计算S/C、W/C和W/S的两组位置配对效应：同序号相除减1，逐方向列出，不把不同phase拼接。
每项比较的 `ε` 取两臂各自第二次/第一次变化绝对值的较大者，`M=max(5%,2ε)`。
两次READ/WRITE均为正且不小于M才记对应 `SCREEN_CONTINUE`；不足则记方向不明或分辨率不足，
不宣称等价/普遍无效。ε≥5%须保留细效应分辨率不足标签；明显大于2ε仍可作为升级筛选信号，
但六格L1本身不签生产普适收益或精确置信区间。CV/末窗/排空非零不作否决条件。

必须区分：**证据有效、180秒突发有收益、优于另一缓存配置、达到历史数值目标、可生产交付**，
这五项不能用一个PASS代替。若仅首段好看而全程未过线，不能称本目标完成；若全程过线且后段衰减，
应如实登记“有限突发收益”，不能再用非稳态理由抹去。
