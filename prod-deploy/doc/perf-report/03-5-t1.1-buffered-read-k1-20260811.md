## 8. 异常与偏差

1. **PROGRESS.txt 的 median 格式问题**：wrapper 用 `grep rounds.tsv | awk '{print $3}'` 提取 median，但 rounds.tsv 每个 item 有 5 行（5 轮），导致 grep 返回 5 行，PROGRESS.txt 中每个 median 字段变成多行。不影响数据正确性（原始逐轮值都在 rounds.tsv 中），但 PROGRESS.txt 可读性差。
2. **冒烟测试已清理**：T11-SMOKE 产物已从 rounds.tsv 和 /tmp/opencode-fullbaseline-v4/ 中清除，不影响正式数据。
3. **wrapper 未在首 run 后暂停等确认**：任务书要求首 run 后回报等确认再继续，但 wrapper 设计为连续跑 6 run。首 run 数据回报后用户确认继续，wrapper 已在跑 T11-B1。不影响数据完整性。
4. **无其他异常**。
