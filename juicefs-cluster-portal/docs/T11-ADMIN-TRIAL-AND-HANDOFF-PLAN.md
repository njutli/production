# T11管理员试运行与交付计划

## 1. 试运行方式

1. 前2小时Codex保持当前任务运行，每5分钟读取并判断一次157监控器样本，共25次；Prometheus同时检查最近5分钟内14个targets是否始终在线。
2. 两小时监控器只写RUN私有日志，不执行服务重启、修复、删除或配置修改；Codex发现异常时立即保留并分析证据，不自动变更现场。
3. 只有前2小时全部通过，Codex才在157启动长期`continuous`只读记录器、确认首个样本成功后退出；平台和记录器继续运行。
4. 用户后续通知检查时，Codex读取后台日志和服务累计计数，补做24小时终点只读签收；后台记录器的停止或清理另行确认。

## 2. 监控内容

- 152管理服务active/disabled/static状态、`NRestarts`和端点健康；
- Prometheus当前14/14及最近5分钟连续14/14；
- T09 SQLite完整性、ready状态、generation推进和快照年龄不超过180秒；
- Portal不可进入专用控制挂载；
- Ceph `HEALTH_OK`、PD/TiKV PID和三处关键挂载；
- 157 forwarder active/disabled、`NRestarts=0`、任务数不超过32及业务挂载不变；
- 152系统盘保留至少2 GiB。

## 3. 异常与权限边界

任何异常仅写入日志，不自动处置。长期日志达到16 MiB时记录器自动停止，禁止无界占用157系统盘。需要停止/启动服务、修改配置或清理文件时，必须另行给出152或157上的完整命令并取得用户批准。

## 4. 交付条件

前2小时无异常，且后续24小时终点检查未发现重启、target中断、T09过期、Ceph异常或业务指纹变化后，整理访问方式、证书、服务启停、数据备份、故障排查和精确回滚说明，完成T11交付。
